# 환불 처리

환불은 **결제 내역 → 결제 추가**에서 금액을 음수로 넣는다. (Slack `/결제`와 시트 동기화는 0 이하 금액을 받지 않는다)

## 1. 마이그레이션 적용

Supabase 대시보드 → SQL Editor 에 `supabase/migrations/020_refund_to_project.sql` 내용을 붙여넣고 실행한다.

## 2. 달라지는 것

| 상황 | 이전 | 이후 |
|---|---|---|
| 상호명만 넣고 저장 | 완납 프로젝트는 매칭에서 빠져 **계약금액이 마이너스인 새 프로젝트**가 생김 | 그 상호명의 프로젝트 중 입금이 있는 가장 최근 건에 연결. 새 프로젝트·클라이언트는 만들지 않음 |
| 프로젝트를 골라 저장 | 입금완료만 줄고 계약금액은 그대로 → 잔여가 남은 것처럼 보임 | 계약금액에서 환불액을 차감 (계약 1,000,000 · 환불 300,000 → 계약 700,000 · 입금 700,000) |
| 받은 돈이 전부 돌아감 | 진행중 그대로 | 프로젝트 **취소** 처리. 이후 같은 클라이언트 결제는 새 프로젝트로 감 |
| 환불 삭제 / 연결 해제 | — | 차감했던 계약금액을 되돌림 (취소 상태는 되돌리지 않으니 필요하면 직접 수정) |

프로젝트 목록의 입금완료 칸에 `환불 -300,000` 이 함께 표시된다.

## 3. 주의

- 마이그레이션 이전에 **손으로 계약금액을 줄여둔 환불 건**은 그대로 두는 게 안전하다. 그 건을 다시 프로젝트에 연결하거나 프로젝트를 바꾸면 한 번 더 차감된다.
- 연결할 프로젝트를 못 찾으면(상호명 오타, 입금 기록 없는 클라이언트 등) 미연결로 저장되고 사이드바 배지에 잡힌다. 목록에서 "연결 필요"를 눌러 이어주면 그때 차감된다.
